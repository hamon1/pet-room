# 3단계 트러블슈팅 기록 (2026-10-29)

## 1. CI에서 테스트 실패 원인을 볼 수 없음

- **상황**: 이벤트 통합 테스트가 CI에서 실패했는데, 오류 표시에는 테스트 이름만 남고 실패 이유가 없었음 (작업 환경에서 CI 로그·리포트 다운로드가 막혀 있음)
- **원인**: 기존 오류 표시 단계는 Gradle 콘솔 출력만 걸렀는데, 콘솔에는 단언 메시지가 나오지 않음
- **조치**: 테스트 결과 XML의 `<failure message="...">`를 읽어 CI 오류 표시로 남기도록 워크플로 수정
- **실제 원인**: 투약 기록 테스트 데이터에 필수 항목(내용)이 빠져 400이 났음 → 테스트 데이터 수정

## 2. 테마 색이 이벤트 표시를 덮어씀

- **상황**: 화면 확인 중 주요 이벤트 칩(의료 빨강, 유통기한 주황 등)이 모두 같은 색으로 보임
- **원인**: 테마용으로 추가한 `body:not(.bw) .chip` 규칙의 우선순위가 `.chip.med`보다 높았음
- **조치**: 테마 규칙을 `:where(body.bw) .chip`으로 바꿔 우선순위를 낮추고, 파스텔·블랙 앤 화이트 두 테마에서 화면을 다시 확인
