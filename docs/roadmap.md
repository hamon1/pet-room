# 로드맵

기획서의 MVP 범위를 단계별로 나눠 구현합니다. 각 단계는 PR 단위로 진행하고, 끝날 때 이 문서의 체크를 갱신합니다.

## 1단계 - 기반 구축 (진행 중)

- [x] 저장소, 설계 문서 (아키텍처, ERD, API, 의사결정)
- [x] 백엔드 골격: Spring Boot, PostgreSQL, Flyway, 공통 오류 응답, 헬스체크
- [x] 회원가입·로그인 (이메일, JWT)
- [x] 반려동물 등록·조회·수정·삭제 (분류·세부 분류·관리 방식 검증)
- [x] 프론트엔드 골격: Next.js, PWA manifest, 로그인·반려동물 목록·등록 화면
- [x] CI: 백엔드 테스트, 프론트엔드 빌드
- [ ] CI 통과 확인 (푸시 후)

## 2단계 - 기록

- [ ] 건강 상태 기록 (날짜별, 같은 날 덮어쓰기)

- [ ] 반려동물 상세 화면 (건강·의료·특수 항목 탭)

## 3단계 - 먹이·달력
